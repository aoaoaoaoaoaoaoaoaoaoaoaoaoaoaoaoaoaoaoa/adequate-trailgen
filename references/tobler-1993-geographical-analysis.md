## Synopsis

The report develops anisotropic geographic models. Its walking example converts local slope to travel velocity using a hiking function estimated from Imhof's 1950 empirical data, then computes minimum-time paths and isochrones over an elevation grid. The commonly transcribed function is `v = 6 exp(−3.5 |s + 0.05|)` km/h for fractional grade `s`.

## Source Assessment

The report's equation is presented graphically, so exact machine-readable transcription is better corroborated by later literature. The function predicts travel time, not energy, and the customary 0.6 off-road multiplier is not part of a nuanced terrain model.
